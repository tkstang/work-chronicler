## Changes

- **Breaking:** five package skills are renamed to `work-chronicler-[manager-]<verb>-<object>`. `skills install` migrates installs under the old names on every selected tool. It keeps an old copy whenever a replacement link or another tool's install still resolves into it, treats any occupant of a destination as an overwrite conflict, and `skills list` flags old names. The old → new map lives in `RENAMED_SKILLS`.
- `skills install` gains `--tool <tool...>`, `--method`, `--yes`, `--overwrite` and `--keep-old` for runs without prompts.
- `fetch github --reviews` and `fetch all --reviews` (opt-in, IC only) record the reviews and inline review comments you gave on other people's PRs in the fetch range. Each reviewed PR is stored once at `work-log/pr-reviews/<org>/<repo>/<number>.md`, outside `pull-requests/`, and never counted as authored. Rate limits during the owner lookup are fatal. A fetch refuses to run when the work log holds another reviewer's records.
- `status`, `filter` and the new read-only MCP tool `search_pr_reviews` cover review records. `status` and `search_pr_reviews` leave out records from other reviewers and show who wrote them.
- The self-review, resume-bullet, update-resume and summarize skills cite reviews as review work. They cite only records whose `reviewer` matches your normalized `github.username`, and say how many they left out.
- 0.5.0: `package.json` version, CHANGELOG section with migration notes. The MCP server now reports the package version instead of a hardcoded `0.1.0`.
- Docs (README, `documentation/`, AGENTS.md) updated to match: the naming rule, review commands, storage path, MCP tool and skill counts.
